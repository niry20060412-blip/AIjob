# AI 求职助手 - Chrome 岗位采集器

## 目录结构

```text
extension/
├── manifest.json
├── content.js
└── popup/
    ├── popup.html
    ├── popup.css
    └── popup.js
```

## 功能边界

本插件只做当前页面公开岗位信息的辅助采集：

- 读取当前页面标题
- 读取当前页面 URL
- 尝试提取岗位名称
- 尝试提取公司名称
- 尝试提取薪资
- 尝试提取城市
- 提取页面主要文本作为岗位 JD
- 允许用户在 popup 中编辑采集结果
- 支持复制 JSON 到剪贴板
- 支持打开 Web 应用导入页

不会做：

- 不自动登录
- 不读取账号密码
- 不自动投递
- 不自动点击页面按钮
- 不自动发送消息
- 不绕过平台限制

所有投递动作必须由用户自己确认完成。

## 安装方式

1. 打开 Chrome。
2. 访问 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本目录：`ai-job-assistant/extension`。

## 使用方式

1. 打开任意招聘网站的岗位详情页。
2. 等岗位详情内容完全加载出来。
3. 点击浏览器右上角插件图标。
4. 插件会读取当前页面 DOM，尝试填充岗位信息。
5. 在 popup 中人工检查并编辑岗位名称、公司、薪资、城市和 JD。
6. 点击“复制到剪贴板”，再粘贴到 Web 应用的“导入岗位”入口。
7. 或点击“发送到 Web 应用”，插件会打开 `http://127.0.0.1:3000/job-matching?importJob=1`，并把 JSON 复制到剪贴板，用户再粘贴确认导入。

## 识别不了时怎么办

1. 在 Chrome 扩展管理页 `chrome://extensions/` 找到本插件，点击“重新加载”。本地插件代码修改后必须重新加载才会生效。
2. 回到招聘网站岗位详情页，刷新页面，等 JD 内容完全加载后再点插件。
3. 新版本 popup 会先尝试读取 content script；如果读取不到，会使用 `chrome.scripting.executeScript` 主动注入采集逻辑，所以通常不需要等页面预先注入。
4. 如果岗位名称、公司、薪资为空，但 JD 有内容，可以先手动补齐字段再复制。
5. 如果 JD 也为空，说明该网站可能使用了 iframe、Shadow DOM、强动态渲染或限制插件读取；第一版不绕过平台限制，可手动复制 JD 到 Web 应用。

## Web 应用导入逻辑

Web 应用的岗位匹配页已增加“导入岗位”入口：

- 粘贴插件复制的 JSON；
- 点击“导入并填充 JD”；
- 自动填充岗位 JD 文本框；
- 保存到浏览器 localStorage 岗位库；
- 用户确认简历和 JD 后再点击“开始匹配分析”。
